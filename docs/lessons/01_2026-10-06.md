# Einheit 01: GitHub, Zusammenarbeit und erster roter Test

**06.10.2026 · 14:00–16:15 · Continuous Delivery WS 2026/27**

Lesen Sie zunächst [Lesson 01: Das Release Board verstehen](../lesson-01/README.md). Dort sind Verhalten, Tests und Artefakt erklärt.

## Mindestausgangsszenario

Git und Node.js 24; ein GitHub-Konto je Person; die entpackte Startvorlage aus Moodle. Ein gemeinsames leeres GitHub-Repository wird erst in dieser Einheit angelegt.

**Benötigte Dateien:** README.md, package.json, package-lock.json, src/, test/, scripts/, .github/workflows/ci.yml, .gitignore und release.txt. Noch keine Container-, IaC- oder Java-Dateien nötig.

## Startprüfung

Führen Sie die Befehle im Repository-Stamm aus; ein angegebenes `cd` wechselt anschließend in das jeweilige Labor.

```sh
npm ci
npm run check
npm test
```

**Erwartung:** Drei Tests bestehen. release.txt enthält genau: Release message: Ready for delivery.

Bei fehlender Voraussetzung verwenden Sie den beschriebenen [Wiedereinstieg](README.md). Halten Sie fehlende Zugänge und ausstehende Nachweise konkret fest.

## Arbeitsauftrag

Legen Sie gemeinsam das GitHub-Repository an und laden Sie die zweite Person ein. Bearbeiten Sie die Git Delivery Challenge. Erzeugen und reparieren Sie anschließend den Vertragsfehler in src/release.js.

Die [Schrittanleitung](../00-github-gemeinsam.md) ergänzt diesen Einstieg. Legen Sie vor Änderungen einen eigenen kurzen Branch an und integrieren Sie nur einen geprüften Stand.

## Checkliste für den Abschluss

- [ ] Die Startprüfung war erfolgreich oder der Ersatzweg wurde dokumentiert.
- [ ] Die Aufgabe wurde bearbeitet; fachliche Entscheidungen sind begründet.
- [ ] Folgender Nachweis liegt vor: Gemeinsamer Repository-Link; zwei nachvollziehbare Beiträge; roter und grüner Actions-Lauf mit Commit-IDs; JUnit-Bericht.
- [ ] Eigene Änderungen sind gezielt versioniert; keine Zugangsdaten oder generierten Laufzeitdaten wurden eingecheckt.
- [ ] Übergabe: main ist grün; beide Personen können klonen und pushen. Vervollständigen Sie fehlende Nachweise bis 19.10.2026.
